# =====================================================================
#  AUTO RESEARCH - standalone drop-in
# =====================================================================
#  Drop this single file into:
#     Steam/steamapps/common/Hearts of Iron IV/common/on_actions/
#  Nothing else to install. No descriptor, no mod folder, no launcher.
#  Delete the file to uninstall.
#
#  Every AR_INTERVAL days you are granted one technology that you do
#  not have and that is not ahead of the calendar.
#
#  --- HOW THE PICK WORKS ------------------------------------------
#  The list below is sorted by year, earliest first. The first entry
#  that is (a) unresearched and (b) not in the future gets granted,
#  and the pass stops there.
#
#  Your case: it is 1940, Infantry Equipment III is done.
#    infantry_weapons3  1942  -> in the future, skipped
#    construction3      1940  -> GRANTED
#  It never stalls on a tech two years out of reach.
#
#  --- SETTINGS ------------------------------------------------------
#  Interval: search this file for "= 5 }" on the two ar_cd lines and
#  change both to the same number. 5 days is about 5 seconds at speed
#  5. Use 1 for near-instant.
#
#  Reach further ahead: lower a YEAR number. Setting infantry_weapons3
#  to 1940 makes it grab that gun two years early instead of skipping.
#
#  Remove a tech: delete its whole if = { ... } block.
#
#  --- WARNINGS ------------------------------------------------------
#  * A Steam update or "Verify integrity of game files" DELETES this
#    file. Keep a backup copy somewhere else.
#  * Tech ids are unverified against your build. A wrong id fails
#    silently - the block just never fires. Check names against
#    common/technologies/ and check logs/error.log on first load.
#  * Human players only. The AI is untouched.
#  * No doctrines: they are mutually exclusive and set_technology
#    ignores that, so it would hand you incompatible doctrine paths.
# =====================================================================
