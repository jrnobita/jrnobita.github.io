# =====================================================================
#  AUTO RESEARCH - tech tables
# =====================================================================
#  Each lane is a list of (tech id, earliest sensible year), sorted by
#  year ascending. ar_try walks the list and takes the FIRST entry that
#  is both unresearched and not ahead of the calendar.
#
#  That ordering is the whole optimisation. Worked example, the one you
#  described:
#
#     it is 1940, Infantry Equipment II is done
#     -> infantry_weapons2 is a 1939 tech  -> in era  -> taken
#     it is 1940, Infantry Equipment III is done
#     -> infantry_weapons3 is a 1942 tech  -> skipped
#     -> support_weapons1 (1939)           -> maybe already done
#     -> artillery2 (1941)                 -> skipped
#     -> construction3 (1940)              -> in era -> taken
#
#  So it never burns the timer on a tech two years out of reach; it
#  drops sideways onto the best thing the era actually offers.
#
#  ---------------------------------------------------------------
#  TUNING: the YEAR values are "when is this reasonable to own", not
#  literally the tech's start_year from the vanilla files. Raise a
#  year to make the mod hold off longer, lower it to make the mod
#  grab it sooner. Reorder lines to change preference inside a lane.
#
#  VERIFY BEFORE ADDING: tech ids change between game versions and
#  DLC (NSB reworked armour, BBA reworked aircraft). If you add a
#  line with a tech id that does not exist in your version, the game
#  logs an error and that line silently does nothing. Check the id
#  against Hearts of Iron IV/common/technologies/ first.
#
#  DOCTRINES ARE DELIBERATELY ABSENT. Doctrine branches are mutually
#  exclusive choices; set_technology ignores that restriction and
#  would happily hand you two incompatible doctrine paths. Pick those
#  yourself.
# =====================================================================
