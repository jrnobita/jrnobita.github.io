What it does

Both limits, always visible

Session and weekly percentages in the menu bar, next to your plan name. Green under 50, amber to 79, red above.

Reset countdowns

Not just how much is used, but how long until each window clears.

Notify before the wall

Pick a threshold from 50 to 95 percent. One alert per window, no repeats.

Recent history

A small graph under each meter showing how the last stretch has trended.

Settings in the menu

Threshold, label style, graph and idle hiding are all clicks. Nothing needs an editor.

Stays quiet

Responses cache for two minutes, so clicking around costs nothing and rate limits stay clear.

How it came together
v1.0.0

Finding the number

Nothing public exposes subscription usage. The browser and desktop app leave nothing on the machine, but Claude Code stores a token in the Keychain. Everything else followed from that.

v2.0.0

Making it speak up

A meter you have to look at is half a tool. This pass added notifications, the plan name, a history graph, and a settings menu.

v3.0.0

Fixing the wrong answer

Rate limits appeared and a slower timer looked like the fix. It was not. The requests came from clicking, not the schedule. Caching solved it.

Get it running

Downloads the current version straight from the repo, so you always get the latest.

Download latest ↓ All releases

Or install from the terminal. This shows you the installer before running it. Press q to exit the preview, then run the second line.

# read it first
curl -fsSL https://raw.githubusercontent.com/jrnobita/claude-usage-menubar/main/install.sh \
  -o /tmp/claude-usage-install.sh && less /tmp/claude-usage-install.sh

# then run it
bash /tmp/claude-usage-install.sh
REQUIRES  macOS  ·  SwiftBar  ·  Claude Code signed in  ·  Claude Pro or Max
Straight answers

What it does not do

It reads an undocumented endpoint

The same one Claude Code uses internally. Anthropic can change or remove it at any time, and the consumer terms restrict automated access, so whether a read-only status check sits inside them is unclear. Worth knowing before you install it.

It consumes nothing. No prompts, no output, no tokens. The request asks for a number and receives a number.

It bypasses nothing. Every figure it shows is already available in /usage and on the settings page. It changes where you see them, not what they are.

It stays on your machine. A shell script, no server, no telemetry, no account. One request to Anthropic's own API using a token already in your Keychain.
